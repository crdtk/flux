Always search for options online before recommending any component. Never guess prices, availability, socket compatibility, or specs from memory.

**Why:** Multiple wrong recommendations were made from memory — Supermicro X11SDW (RDIMM not SODIMM), Arctic Alpine 17 (LGA1700 not LGA1200), Jonsbo CR-1200 (LGA1200 not listed), DPP13 connector count (2x 12VHPWR not 4x). Each error wasted time and trust.

**How to apply:** For every component recommendation: (1) search Geizhals/Amazon.de/retailer for actual specs, (2) verify socket/connector compatibility from official specs, (3) provide clickable URLs with real prices and stock status. No exceptions.
