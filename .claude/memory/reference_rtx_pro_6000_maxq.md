NVIDIA RTX PRO 6000 Blackwell Max-Q Workstation Edition:
- 96 GB GDDR7, 512-bit bus, 1.8 TB/s memory bandwidth
- 24,064 CUDA cores, 752 Tensor cores, GB202 die
- 300W TDP, blower-style cooler, dual-slot
- ~5-14% slower than full Workstation Edition (600W)
- PCIe 5.0 x16 native
